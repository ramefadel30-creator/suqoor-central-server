خادم صقور الصحراء المركزي

هذا المجلد يحتوي على:
- index.html: نسخة اللعبة المعدلة لتتصل بخادم WebSocket مركزي.
- server.js: خادم الغرف والرسائل.
- package.json: إعدادات تشغيل الخادم.

مهم قبل الاختبار:
1) انشر هذا المجلد على خدمة Node.js مجانية تدعم WebSocket (مثلاً Render Web Service).
2) بعد النشر ستحصل على عنوان HTTPS مثل https://اسم-الخدمة.onrender.com
3) حوّل العنوان إلى WSS هكذا: wss://اسم-الخدمة.onrender.com
4) افتح index.html وابحث عن COOP_SERVER_URL واستبدل PUT-YOUR-FREE-SERVER-URL-HERE بعنوان WSS الحقيقي.
5) ارفع نسخة HTML المعدلة إلى تطبيق HTML-to-APK وأعد بناء APK على الهاتفين.

ملاحظة: الخادم يدير إنشاء الغرف ذات الستة أرقام ويرحل رسائل اللاعبين. في هذه النسخة اللاعب المضيف يشغّل محاكاة اللعبة ويرسل الحالة إلى اللاعب الثاني؛ لذلك ليست محاكاة خادمية كاملة بعد.
